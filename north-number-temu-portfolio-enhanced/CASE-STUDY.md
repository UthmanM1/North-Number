# North & Number — Marketplace Implementation

## Brief
Demonstrate how a UK personalised-signage manufacturer could structure a Shopify-to-marketplace operation for house signs and solar illuminated address products.

## Problem
Automatic imports can create weak titles, incomplete attributes, inconsistent variants and unclear compliance status.

## Solution
Shopify is treated as the canonical product source. A marketplace QA layer handles SKU validation, category mapping, attributes, title/feature optimisation, variants, images, compliance evidence and publication monitoring.

## Solar compliance approach
The demo deliberately does not claim a particular certificate is universally required. It shows a controlled workflow: identify the marketplace request, obtain relevant supplier documentation, match evidence to the SKU/product, review it, then move the listing toward publication.

## Application wording
“I built a marketplace implementation portfolio project around a fictional UK signage manufacturer. It demonstrates how I would structure a Shopify catalogue for marketplace export, manually improve imported listings, manage variants and attributes, and introduce a compliance gate for solar products so evidence is collected and reviewed before publication.”
