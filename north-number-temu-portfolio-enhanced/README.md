# North & Number — Temu Marketplace Portfolio

A fictional UK personalised-signage marketplace implementation portfolio.

## Demonstrates
- Premium signage storefront and product mockups
- Shopify-style catalogue/admin experience
- Product editor with marketplace-ready fields
- Temu-style listing preparation workflow
- Sync health and exception-resolution screens
- Solar/electrical evidence and compliance gate
- Portfolio case-study narrative

## Deploy
`npm install` then `npm run dev`, or push to GitHub and import into Vercel as a Next.js project.

## Honest portfolio positioning
This is a fictional demonstration project. Do not describe it as a real Temu seller account or claim real sales, certificates, seller performance or client results. Use it to demonstrate the workflow and your ability to reason about marketplace operations.

An accompanying case-study PDF is included in the project package.
